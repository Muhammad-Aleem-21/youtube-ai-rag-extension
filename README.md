Go to your repo's Releases page and download youtube-ai-extension.zip.

Unzip it into a folder, and keep the folder somewhere permanent. Chrome loads the extension from that folder, so deleting or moving it breaks the extension.

Open Chrome and go to chrome://extensions.

Turn on Developer mode (the toggle in the top right).

Click Load unpacked and select the unzipped folder (the one that contains manifest.json).

The extension now appears in the list. Click the puzzle icon in the toolbar and pin it if you want.

Open any YouTube video, click the 🤖 button, and ask a question.
